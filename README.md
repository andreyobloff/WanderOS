# WanderOS

WanderOS — учебно-продуктовый Telegram-бот для генерации безопасных городских маршрутов, случайных точек и мини-квестов по Москве.

## Цель проекта

Разработать Telegram-сервис, который помогает пользователю получать персонализированные городские маршруты и задания с учётом геолокации, погоды, истории активности и правил безопасности.

## Основные функции MVP

- регистрация пользователя;
- настройка профиля;
- генерация случайной городской точки;
- генерация мини-квеста;
- проверка погодных условий;
- сохранение истории маршрутов;
- отчёты по активности;
- визуализация статистики;
- пакетная генерация квестов;
- планировщик маршрутов;
- SQLite-хранилище;
- логирование и обработка ошибок.

## Технологии

- Python 3.10+
- Telegram Bot API
- SQLite
- requests
- pandas
- matplotlib
- APScheduler
- LLM API

## Структура проекта

src/wanderos — основной код приложения  
docs — проектная документация  
reports — отчёты по практическим работам  
data — демонстрационные данные  
tests — тесты и тест-кейсы  
scripts — служебные скрипты  
exports — экспортируемые отчёты  
logs — журналы работы приложения  

## Безопасность

Проект не хранит токены и API-ключи в репозитории. Для секретных значений используется файл .env, а пример структуры переменных приведён в .env.example.
